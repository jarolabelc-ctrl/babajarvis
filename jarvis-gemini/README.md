# JARVIS Gemini — Android y Windows

**Guía en español:** consulta [`README-GITHUB.md`](README-GITHUB.md) para ejecutar el proyecto, prepararlo para Android y publicarlo en GitHub.

Este repositorio combina una interfaz holográfica web con una configuración inicial para Google Gemini y Capacitor.

> **Importante:** el repositorio contiene código fuente, no un APK compilado. El control de programas de Windows aún no está implementado. No publiques tu clave de Gemini: la variable `VITE_GEMINI_API_KEY` incluida en una aplicación frontend puede extraerse.

## Quick start

```bash
npm ci
```

Copia `.env.local.example` a `.env.local`, añade tu clave de Gemini y ejecuta:

```bash
npm run dev
```

Revisa la guía en español antes de preparar el APK o publicar el repositorio.
